# Enterprise Collaboration Workflow (ECWF) - Microservices

## Overview

This project contains the initial setup for converting the existing Authentication module into a FastAPI-based Microservices Architecture.

## Technology Stack

- Python 3.12
- FastAPI
- SQLAlchemy 2.0
- Pydantic v2
- Alembic
- MySQL
- PyMySQL
- JWT
- Passlib (Bcrypt)
- HTTPX
- Pytest
- Docker & Docker Compose

## Services

- Identity and Authentication Service
- Registration and Verification Service
- Organization and Tenant Service
- Notification Service

> Note: This project contains only the initial project structure. API implementation will be completed in the next phase.
